# Лабораторная работа №1 — работа с сокетами

Проект содержит пять обязательных заданий по сетевому взаимодействию на
Python. Все серверы и клиенты используют стандартную библиотеку `socket`.

## Состав работы

1. UDP-клиент отправляет `Hello, server`, UDP-сервер отвечает
   `Hello, client`.
2. TCP-клиент передаёт основание и высоту треугольника, TCP-сервер вычисляет
   площадь. Выполнен вариант №2.
3. HTTP-сервер загружает HTML-разметку из отдельного файла `index.html`.
4. Многопользовательский TCP-чат обслуживает клиентов в отдельных потоках.
5. HTTP-сервер принимает дисциплину и оценку через POST, хранит записи в
   памяти и возвращает их общей HTML-страницей при GET и POST.

## Структура

```text
laboratory_work_1/
├── socket_lab/
│   ├── udp_server.py     # задание №1: UDP-сервер
│   ├── udp_client.py     # задание №1: UDP-клиент
│   ├── math_server.py    # задание №2: TCP-сервер варианта №2
│   ├── math_client.py    # задание №2: TCP-клиент варианта №2
│   ├── http_server.py    # задания №3 и №5: HTTP на socket
│   ├── chat_server.py    # задание №4: многопользовательский чат
│   ├── chat_client.py    # задание №4: клиент чата
│   └── protocol.py       # строчный протокол TCP-приложений
├── tests/                # модульные и интеграционные тесты
├── docs/index.md         # отчёт по лабораторной
├── index.html            # HTML-шаблон страницы оценок
├── mkdocs.yml            # конфигурация документации
```

## Требования

- Python 3.10 или новее;
- сторонние библиотеки для программ и тестов не требуются;
- MkDocs нужен для сборки сайта с отчётом.

Все команды ниже выполняются из каталога `laboratory_work_1`.

## Задание №1 — UDP-приветствие

Сначала запустите сервер:

```bash
python -m socket_lab.udp_server
```

Затем в другом терминале запустите клиент:

```bash
python -m socket_lab.udp_client
```

После одного обмена сообщениями обе программы завершаются.

## Задание №2 — площадь треугольника

Запустите TCP-сервер варианта №2:

```bash
python -m socket_lab.math_server
```

В другом терминале запустите клиент и введите основание и высоту:

```bash
python -m socket_lab.math_client
```

Сервер вычисляет площадь по формуле `S = a × h / 2`.

## Задания №3 и №5 — HTTP-сервер

```bash
python -m socket_lab.http_server
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080). GET возвращает
страницу из `index.html`. Форма отправляет POST с дисциплиной и оценкой.
Список хранится в оперативной памяти и очищается после остановки сервера.

## Задание №4 — многопользовательский чат

Запустите сервер:

```bash
python -m socket_lab.chat_server
```

В двух или более других терминалах запустите клиентов:

```bash
python -m socket_lab.chat_client
```

Каждый клиент вводит уникальное имя. Для выхода используется команда `/quit`.

## Настройка адресов

У каждой программы доступны аргументы `--host` и `--port`. Клиент и
соответствующий сервер должны использовать один порт. Значения по умолчанию:

- UDP-приветствие — `127.0.0.1:8001`;
- площадь треугольника — `127.0.0.1:8002`;
- чат — `127.0.0.1:8000`;
- HTTP-сервер — `127.0.0.1:8080`.

## Проверка

Создайте изолированное окружение и установите MkDocs:

```bash
python -m venv .venv-docs
source .venv-docs/bin/activate
python -m pip install -r requirements-docs.txt
```

Затем выполните проверки:

```bash
python -m unittest discover -s tests -v
python -m compileall -q socket_lab tests
python -m mkdocs build --strict
git diff --check
```

Отчёт находится в [docs/index.md](docs/index.md).
