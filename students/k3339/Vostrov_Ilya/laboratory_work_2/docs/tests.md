# Тестирование

К проекту написаны unit-тесты на штатном `django.test.TestCase`
(файл `homework/tests.py`). Запуск:

```bash
python manage.py test homework
```

Результат — **15 тестов**, все проходят:

```text
...............
----------------------------------------------------------------------
Ran 15 tests in 2.129s

OK
```

## Покрываемые сценарии

| Класс теста             | Что проверяется |
|-------------------------|-----------------|
| `IndexViewTests`        | главная отдаёт 200 и содержит задания; фильтр по предмету; поиск по тексту и по преподавателю; пагинация (число страниц > 1) |
| `DetailViewTests`       | аноним видит подсказку "зарегистрируйтесь"; ученик успешно сдаёт решение (редирект + запись в БД); повторная сдача не создаёт дубля; учитель видит все работы |
| `RegistrationTests`     | регистрация создаёт пользователя с `Profile.group` и без прав учителя; слабый пароль отклоняется формой |
| `MySubmissionsTests`    | `/my/` требует авторизации (302); страница показывает своё решение и отметку |
| `ClassSummaryTests`     | аноним не получает 500; ученик видит сводку своего класса; учитель может переключать группу и видит таблицу по всем классам |
