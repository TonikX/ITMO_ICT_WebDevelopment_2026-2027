# Выводы

В лабораторной работе реализован простой сайт на Django по теме
"Доска домашних заданий" (вариант 2). Достигнуто:

- **Модель данных**: `Homework`, `Submission`, `Profile` с ограничением
  уникальности "одно задание — одно решение" и автоматической фиксацией даты
  выставления отметки.
- **Клиентские экраны и логика**: список заданий, страница задания, сдача
  решения текстом с изменением/удалением, "Мои работы", "Сводка отметок
  класса", регистрация и вход.
- **Разграничение прав** на клиенте (в разметке по `is_staff`/`is_superuser`)
  и продублировано на сервере: ученик работает только со своими решениями,
  учитель — со всеми и с произвольными группами; отметки выставляет только
  учитель через Django-admin.
- **Стилизация**: Bootstrap 5 (CDN) + небольшой собственный CSS.
- **Пагинация и фильтрация**: `Paginator` (5 на страницу), фильтр по предмету
  и поиск по тексту/преподавателю с сохранением параметров при перелистывании;
  агрегация отметок через `annotate(Count, Avg)`.
- **Качество**: 15 unit-тестов, покрывающих маршруты, права и формы;
  повторяемое наполнение демо-данными командой `seed_demo`; отчёт в **MkDocs**.

## Что можно улучшить в дальнейшем

- Смена пароля и восстановление по e-mail (штатные Django-аутентификация
  расширяется декораторами/вьюхами).
- Ограничение сдачи после срока на сервере (в текущей версии "после срока" —
  только предупреждение).
- Загрузка файлов с решением (не только текст) — модель `Submission`
  расширяется полем `FileField`.
- Развёртывание: `gunicorn` + PostgreSQL + `manage.py collectstatic`
  (конфигурация уже предусмотрена переменными окружениями).
