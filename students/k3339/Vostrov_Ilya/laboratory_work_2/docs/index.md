## Цель работы

Получить навыки создания веб-сервисов на фреймворке Django
(модель MVC, шаблоны, формы, разграничение прав, пагинация и фильтрация)
и оформить отчёт в MkDocs.

## Тема (вариант 2)

"Доска домашних заданий". Сущность "Задание" содержит: **предмет,
преподаватель, дата выдачи, период выполнения (срок сдачи), текст задания,
информацию о штрафах**.

Обязательные функции по условию:

- регистрация новых пользователей;
- показ всех ДЗ (по срокам и описанию) с фильтрацией/поиском;
- сдача решения **текстом**;
- учитель выставляет **оценочную отметку** через Django-admin;
- **сводка отметок класса**;
- пагинация списков.

## Стек

| Компонент  | Технология                                    |
|------------|-----------------------------------------------|
| Язык       | Python 3.9+                                   |
| Фреймворк  | Django 3.2 (встроенная ORM, шаблоны, формы)   |
| БД         | SQLite по умолчанию; PostgreSQL — переключается env-переменной `DB_ENGINE` |
| UI         | Bootstrap 5 (CDN) + собственный CSS           |
| Отчёт      | MkDocs + Material                             |

## Реализованные возможности

- регистрация, вход/выход пользователя (штатная модель `auth` Django);
- список ДЗ: фильтр по предмету, поиск по тексту/преподавателю, пагинация по 5;
- страница задания: сдача текстом, изменение/удаление своего решения
  (пока не выставлена отметка), предупреждение "после срока";
- "Мои работы": все решения пользователя с отметками (пагинация);
- "Сводка отметок класса": агрегация отметок по учебной группе, средние баллы;
  у учителя — выбор группы и таблица по всем классам;
- панель администратора: выдача отметок, фильтры и поиск по работам;
- разграничение прав ученик/учитель на стороне шаблонов и на стороне сервера;
- unit-тесты (15) на основе `django.test.TestCase`.
