# ЛР3. Операции

Система предоставляет следующие функции:

- ведение справочников профессий и уровней образования - единый список
  профессий для всех записей системы и упорядоченные уровни образования
  (поле `priority`), без которых невозможен корректный подбор: соискателю
  со средним образованием не предлагается вакансия, требующая высшее;
- регистрация работодателей и публикация вакансий с указанием требований
  (профессия, уровень образования, минимальный стаж, разряд) и условий
  оплаты (зарплатная вилка), фиксацией даты подачи и статуса;
- регистрация соискателей и ведение их резюме: профессия, образование,
  стаж, квалификационный разряд, контакты, последняя зарплата - основа
  для расчёта пособия;
- подбор вакансий соискателю по профессии, образованию, стажу и разряду:
  вакансия попадает в подбор только при соответствии всем требованиям
  одновременно;
- оформление заявок на вакансии и отслеживание их статусов
  (рассматривается, принята, отклонена); при приёме соискателя вакансия
  закрывается автоматически;
- запись соискателей на курсы переквалификации и учёт присвоенных
  разрядов: по завершении курса полученный разряд переносится в резюме
  соискателя;
- назначение и учёт пособий по безработице: сумма рассчитывается от
  последней зарплаты на момент назначения и фиксируется, ведутся даты
  начала и окончания выплат и статус (выплачивается или прекращено).

## Эндпоинты

Авторизация (Djoser):

| Метод и адрес | Назначение |
|---|---|
| POST `/auth/users/` | регистрация пользователя |
| POST `/auth/token/login/` | вход, возвращает `{"auth_token": "..."}` |
| POST `/auth/token/logout/` | выход, аннулирует токен |
| GET `/auth/users/me/` | данные текущего пользователя |

CRUD - для каждой сущности пара адресов (список+создание и
чтение/изменение/удаление одного): `/api/professions/`, `/api/educations/`,
`/api/employers/`, `/api/courses/`, `/api/applicants/`, `/api/vacancies/`,
`/api/enrollments/`, `/api/applications/`, `/api/allowances/`.
Вложенные данные возвращают детальные адреса:
`GET /api/applicants/{id}/` (заявки, пособия, курсы),
`GET /api/employers/{id}/` (вакансии),
`GET /api/courses/{id}/` (записавшиеся соискатели).

Аналитика и отчёты:

| Метод и адрес | Назначение |
|---|---|
| GET `/api/analytics/professions-without-vacancies/` | профессии соискателей, не представленные в вакансиях |
| GET `/api/analytics/matching-vacancies/` | все подходящие вакансии для каждого соискателя |
| GET `/api/analytics/offer-days/` | дни с момента предложения по заявкам незакрытых вакансий |
| GET `/api/analytics/active-allowances/` | количество действующих пособий |
| GET `/api/analytics/high-education-vacancies/` | вакансии с высшим образованием, зарплата 5000-60000 |
| GET `/api/reports/employers-open-vacancies/` | открытые вакансии каждого предприятия и их количество |

Все эндпоинты, кроме авторизации, требуют заголовок
`Authorization: Token <ключ>`.

## Примеры запросов и ответов

Без токена:

```text
GET /api/professions/ -> 401
{"detail": "Учетные данные не были предоставлены."}
```

Вход:

```text
POST /auth/token/login/
{"username": "admin", "password": "admin12345"}
-> 200 {"auth_token": "c61793b2af1cb8d1f50d705d0781a8dc4775facc"}
```

Некорректная вакансия (зарплатная вилка):

```text
POST /api/vacancies/  (salary_min: 70000, salary_max: 50000)
-> 400 {"non_field_errors": ["Зарплата от не может превышать зарплату до"]}
```

Принятие заявки закрывает вакансию:

```text
PATCH /api/applications/23/ {"status": "accepted"} -> 200
GET /api/vacancies/22/ -> 200 {"id": 22, "status": "closed", ...}
```

Аналитика на данных:

```text
GET /api/analytics/active-allowances/ -> 200 {"active_allowances": 2}
GET /api/analytics/high-education-vacancies/ -> 200 {"vacancies_count": 1}
GET /api/analytics/professions-without-vacancies/
-> 200 [{"id": 7, "name": "Юрист", "description": "Правовое сопровождение"}]
```

## Бизнес-правила

| Правило | Где реализовано |
|---|---|
| Уникальность паспорта, ИНН, названий, уровня образования | `unique=True` в моделях |
| Уникальность пары "соискатель - вакансия", "соискатель - курс", "соискатель - пособие" | `UniqueConstraint` |
| Зарплата "от" не превышает зарплату "до" | `VacancySerializer.validate` |
| Дата окончания пособия не раньше даты начала | `AllowanceSerializer.validate` |
| Завершение курса требует разряда | `CourseEnrollmentSerializer.validate` |
| Сумма пособия считается от последней зарплаты и фиксируется | `AllowanceSerializer.create` |
| Принятая заявка закрывает вакансию | `ApplicationSerializer.update` |
| Разряд из завершённого курса переносится в резюме | `CourseEnrollmentSerializer.apply_completion` |
| Удаление соискателя удаляет его заявки, курсы, пособия; справочники защищены | `on_delete` CASCADE/PROTECT |
| Доступ только после авторизации по токену | Djoser + `IsAuthenticated` |
