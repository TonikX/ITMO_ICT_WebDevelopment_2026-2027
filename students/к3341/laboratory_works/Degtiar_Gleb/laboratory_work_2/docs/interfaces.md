# Интерфейсы

| URL | Интерфейс | Доступ |
|---|---|---|
| `/` | Каталог, поиск по названию/описанию, страна, агентство, даты, цена, сортировка | Все |
| `/tours/<id>/` | Описание, период, оплата, цена, отзывы | Все; скрытые туры только staff |
| `/accounts/register/` | Регистрация, дополнительные атрибуты пользователя | Все |
| `/accounts/login/` | Вход | Все |
| `/accounts/logout/` | Выход (POST) | Пользователь |
| `/tours/<id>/book/` | Создание брони будущего активного тура | Пользователь |
| `/bookings/` | Свои брони, поиск, статус, страницы | Пользователь |
| `/bookings/<id>/edit/` | Изменение количества туристов и пожеланий | Владелец брони |
| `/bookings/<id>/delete/` | Подтверждение удаления и POST | Владелец брони |
| `/tours/<id>/review/` | Отзыв с оценкой 1–10 | Пользователь |
| `/manage/bookings/` | Все заявки с поиском и фильтром статуса | Staff/superuser |
| `/manage/bookings/<id>/confirm/` | Подтверждение POST | Staff/superuser |
| `/manage/sales/` | Подтверждённые продажи и сводка по странам | Staff/superuser |
| `/tours/new/`, `/tours/<id>/edit/` | Создание и изменение тура | Staff/superuser |
| `/practice/owners/`, `/practice/owner/<id>/` | Владельцы, персональные данные, история | Staff/superuser |
| `/practice/owners/new/` | Создание владельца-пользователя | Staff/superuser |
| `/practice/cars/`, `/practice/cars/<id>/` | Автомобили | Staff/superuser |
| `/practice/cars/new/`, `/practice/cars/<id>/edit/`, `/practice/cars/<id>/delete/` | CRUD автомобиля | Staff/superuser |
| `/admin/` | Все модели; дополнительные права Django Admin | Активный staff с правами или superuser |

## Поведение

Пагинация использует шесть элементов на странице. Ссылки страниц сохраняют все GET-фильтры. Некорректные фильтры показывают ошибки формы, а не исключение сервера. В каталоге и учебном списке автомобилей несуществующая страница возвращает 404 по поведению ListView; в остальных списках Paginator.get_page выбирает допустимую страницу.

Меню обычного пользователя показывает «Туры» и «Мои поездки». Администратор дополнительно видит «Заявки», «Продажи», «Практики», «Admin». Доступ к учебным персональным данным ограничен администратором.

Отчёт продаж группирует подтверждённые брони по стране и конкретному туру. Показывает период, количество броней, туристов и сумму; сводка по стране рассчитывается по всем отфильтрованным строкам, независимо от страницы. Оплата и возвраты в проекте не обрабатываются.


## Оформление

Локальные стили, семантические формы с подписями, сообщения об ошибках и успехе, страницы подтверждения удаления, прокручиваемые таблицы, адаптивная сетка. Декоративные изображения нарисованы CSS. На узком экране карточки и фильтры располагаются в один столбец.
