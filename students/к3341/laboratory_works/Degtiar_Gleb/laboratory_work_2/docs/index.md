## Цель и результат

Разработан сайт «Меридиан»: каталог туров, учёт бронирований, отзывы, интерфейс администратора и аналитическая таблица подтверждённых продаж по странам. Используются Python 3.10, Django 3.2.25, PostgreSQL, Jinja2 и собственный CSS. Отчёт собирается средствами MkDocs.

## Соответствие заданию

| Требование | Реализация |
|---|---|
| Название, агентство, описание, период, условия оплаты | `Tour`, отдельные справочники `Agency`, `Country` |
| Регистрация | `RegistrationForm`, расширенная модель `User` |
| Просмотр/резервирование | Каталог, карточка тура, форма бронирования |
| Изменение/удаление своих броней | Представления с выборкой по `user=request.user` |
| Отзывы: даты, текст, рейтинг, автор | `Review`, даты копируются из тура; рейтинг 1–10 |
| Подтверждение в Django-admin | Поле статуса и массовое действие `confirm_selected` |
| Проданные туры по странам в клиенте | `/manage/sales/`, только подтверждённые заявки |
| Разграничение интерфейса | Jinja2-проверки `is_staff or is_superuser`, серверные проверки |
| CSS | `static/style.css`, адаптивные страницы без CDN |
| Пагинация и фильтрация | Каталог, брони, заявки, продажи, учебные списки |
| Практики 2.1–2.3 | `project_first_app`, `accounts`, описание в разделе «Практики» |
| Отчёт MkDocs | `mkdocs.yml`, `docs/` |
