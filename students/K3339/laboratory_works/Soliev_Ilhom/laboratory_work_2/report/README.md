# Отчёт по лабораторной работе 2

Отчёт оформлен средствами MkDocs. Исходный текст находится в `docs/index.md`, иллюстрации — в `docs/images/`.

Запуск локального просмотра из этой папки:

```fish
mkdocs serve
```

Сборка сайта отчёта:

```fish
mkdocs build --strict
```

Общее оглавление работ находится в [README студента](../../README.md).
