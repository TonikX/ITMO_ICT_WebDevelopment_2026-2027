## Цель работы

Овладеть практическими навыками разработки REST API средствами Django REST Framework и реализовать серверную часть приложения по выбранному варианту.

## Задания

### Практическая работа 3.1 — запросы Django ORM

На моделях автомобилей, владельцев и водительских удостоверений создать 6–7 владельцев и 5–6 автомобилей, назначить каждому владельцу удостоверение и от 1 до 3 автомобилей. Затем написать запросы для фильтрации по марке, имени владельца, цвету автомобиля и году владения, получить удостоверение по ID владельца, найти дату выдачи самого старого удостоверения и наиболее позднюю дату владения автомобилем заданной модели. Также подсчитать автомобили по владельцам и маркам и отсортировать владельцев по дате выдачи удостоверения без повторов. В запросах использовать `related_name` и связи many-to-many.

[Полное задание практической работы 3.1](https://rendex85.github.io/ITMO_ICT_WebDevelopment_Docs/lab3/practice1/).

### Практическая работа 3.2 — Django REST Framework

Реализовать API для воинов, профессий и умений: список воинов с вложенными профессиями; список воинов с умениями; получение одного воина по ID вместе с его профессией и умениями; изменение и удаление воина по ID.

[Полное задание практической работы 3.2](https://rendex85.github.io/ITMO_ICT_WebDevelopment_Docs/lab3/practice2/).

### Основное задание — вариант 7 «Птицефабрика»

Разработать серверную часть на Django, Django REST Framework и Djoser с PostgreSQL. Реализовать модели предметной области, API на сериализаторах, регистрацию и токенную авторизацию, получение данных текущего пользователя и документацию эндпоинтов.

Система должна учитывать кур (вес, возраст, породу, яйценоскость и местонахождение), показатели пород и сезонные диеты, цехи и клетки, а также работников, их паспортные данные, зарплаты, договоры и закреплённые клетки. Куры могут перемещаться между клетками; каждая курица должна обслуживаться хотя бы одним работником.

Нужно получать число яиц для кур с заданными параметрами, находить цех с наибольшим количеством кур выбранной породы, считать среднюю дневную яйценоскость на работника, распределение пород по цехам и сравнение показателей породы со средними по фабрике. Также требуется месячный отчёт с числом кур, количеством яиц и средней производительностью по породам и цехам, а также общими итогами по птицефабрике.

[Полное задание лабораторной работы](https://rendex85.github.io/ITMO_ICT_WebDevelopment_Docs/lab3/assignment/).

## Кратко о выполненной работе

Созданы модели и API для основных сущностей птицефабрики, настроены регистрация, авторизация и роли пользователей. Реализованы история назначений кур и работников, проверки целостности данных, учёт выбытия кур и аналитические отчёты по яйценоскости, породам, цехам и работникам.

## Вывод

В ходе лабораторной работы разработано API птицефабрики с учётом связей между данными, бизнес-правил и аналитических запросов.
