## Цель работы

Разработать REST API для учёта птицефабрики: работников, цехов, клеток, кур, пород, яйценоскости и рационов.

## Кратко о выполненной работе

Созданы модели и API для основных сущностей птицефабрики, настроены регистрация, авторизация и роли пользователей. Реализованы история назначений кур и работников, проверки целостности данных, учёт выбытия кур и аналитические отчёты по яйценоскости, породам, цехам и работникам.

## Вывод

В ходе лабораторной работы разработано API птицефабрики с учётом связей между данными, бизнес-правил и аналитических запросов.
