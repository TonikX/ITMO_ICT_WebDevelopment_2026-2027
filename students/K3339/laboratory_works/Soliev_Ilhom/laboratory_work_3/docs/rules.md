# Правила данных

- Вместимость цеха и клетки должна быть больше нуля. Нельзя создать в цехе больше клеток, чем задано его вместимостью, или поселить в клетке больше кур, чем она вмещает.
- Зарплата, вес, стоимость рациона, средний вес породы и число яиц не могут быть отрицательными.
- Для одной курицы нельзя создавать пересекающиеся назначения в клетки. В базе также действует уникальность незакрытого назначения.
- Назначение курицы в клетку проверяется по вместимости и наличию работника, закреплённого за этой клеткой на весь период.
- Снять последнее закрепление работника с занятой клетки нельзя.
- При выбытии курицы API закрывает текущее назначение датой выбытия и сохраняет причину.
- Паспортная серия и номер принимаются при создании или изменении работника как поля только для записи. Обычные списки и карточки API паспортные номера не возвращают.
- Если в клетке в день сбора закреплено несколько работников, яйца распределяются поровну между ними в аналитике по работникам. Это сохраняет общий объём яиц без повторного учёта.

Проверки интервалов и вместимости выполняются в транзакциях с блокировкой затрагиваемой клетки. База данных отдельно обеспечивает числовые ограничения, уникальные ключи и одну открытую запись назначения курицы.
