Привет от сервера на сокетах!

Эту страницу отдал HTTP-сервер, написанный на Python с помощью библиотеки socket.

Сервер принимает TCP-соединение, читает HTTP-запрос, загружает содержимое файла index.html и отправляет его в теле ответа с кодом 200 OK.

Лабораторная работа 1, задание 3. Данилевский Тимур, K3339.
