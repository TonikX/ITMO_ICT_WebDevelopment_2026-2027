# Лабораторная работа №2. Простой сайт на Django

## Цель работы

Овладеть практическими навыками и умениями реализации web-сервисов средствами Django.

## Вариант 5 — Список научных конференций

Интерфейс описывает названия конференций, список тематик, место проведения, период
проведения, описание конференций, описание места проведения, условия участия.

Необходимо реализовать:

- регистрацию новых пользователей;
- просмотр конференций и регистрацию авторов для выступлений с возможностью
  редактирования и удаления своих регистраций;
- написание отзывов к конференциям (текст, рейтинг 1–10, информация о комментаторе);
- указание администратором результатов выступления (рекомендован к публикации или нет);
- таблицу всех участников по конференциям.

## Стек

Python, Django, SQLite, шаблоны Django, Bootstrap 5.
