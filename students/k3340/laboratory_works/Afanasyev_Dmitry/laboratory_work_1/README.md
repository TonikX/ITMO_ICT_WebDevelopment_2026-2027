# Лабораторная работа 1

В папках task_1–task_5 находятся пять заданий. Для запуска нужен Python, дополнительных библиотек нет.

Сначала запустить server.py в нужной папке, затем client.py в другом терминале.
Для заданий 3 и 5 вместо клиента открыть http://127.0.0.1:8080 в браузере.
В задании 4 запустить client.py несколько раз, ввести имена, отправлять сообщения. Выход: /exit.

Пример запуска из этой папки:

```powershell
py -3.12 task_1/server.py
```

В другом терминале:

```powershell
py -3.12 task_1/client.py
```

Перед сменой задания остановить сервер: задания 2 и 4 используют TCP-порт 9999, задания 3 и 5 используют TCP-порт 8080.
В задании 2 сохранён вариант с площадью трапеции. Программы рассчитаны на корректный ввод.

Отчёт находится в [docs/lr1/report.md](docs/lr1/report.md). Он содержит описание, исходники и примеры ожидаемого вывода.

Для просмотра отчёта через MkDocs выполнить из корня репозитория:

```powershell
py -3.12 -m pip install -r students/k3340/laboratory_works/Afanasyev_Dmitry/laboratory_work_1/requirements-docs.txt
py -3.12 -m mkdocs serve
```

После запуска открыть http://127.0.0.1:8000.
