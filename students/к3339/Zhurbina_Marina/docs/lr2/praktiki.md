# Практики 2.1–2.3

Перед лабораторной работой выполнены три практические работы в отдельном
проекте `django_project_zhurbina` (приложение `project_first_app`). Навыки,
полученные в практиках, непосредственно использованы в лабораторной работе.

## Практика 2.1 - первый проект Django

- Создан проект и приложение, изучена файловая структура Django
  (manage.py, settings.py, urls.py, приложение как модуль функциональности).
- Описана модель данных об автовладельцах средствами Django ORM: четыре
  таблицы (владелец, автомобиль, владение, водительское удостоверение) с
  внешними ключами, полями выбора и ассоциативной сущностью.
- Созданы и применены миграции; таблицы заполнены данными через админ-панель;
  создан суперпользователь.
- Написан первый контроллер (страница владельца по id) и шаблон, настроена
  маршрутизация.

## Практика 2.2 - представления и формы

- Настроена связь «многие-ко-многим» через промежуточную модель
  (`ManyToManyField` с `through`).
- Реализованы представления на функциях (список владельцев) и на классах
  (ListView, DetailView, UpdateView для автомобилей).
- Реализованы формы: ввод данных функционально (ModelForm + FBV),
  создание/обновление/удаление автомобилей на основе классов
  (CreateView, UpdateView, DeleteView).

## Практика 2.3 - расширение модели пользователя

- Модель автовладельца заменена на пользователя: `User(AbstractUser)` с
  дополнительными полями (паспорт, адрес, национальность).
- Настроен `AUTH_USER_MODEL`, новые поля отображены в Django-admin.
- Реализован интерфейс создания пользователя с новыми атрибутами
  (на базе `UserCreationForm`).
