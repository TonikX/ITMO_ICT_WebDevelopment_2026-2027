# Модель данных

Модель описана в `tours/models.py`. Используется штатная модель пользователя
Django (расширение пользователя демонстрируется в практике 2.3; для варианта 4
дополнительные атрибуты пользователя не требуются).

## Agency - турагентство

| Поле | Тип | Комментарий |
|---|---|---|
| name | CharField(100) | название |
| city | CharField(50) | город |

Агентство вынесено в отдельную таблицу, так как повторяется в десятках туров:
нормализация устраняет дублирование и делает возможным фильтр туров по
агентству.

## Tour - тур

| Поле | Тип | Комментарий |
|---|---|---|
| agency | FK → Agency | турагентство (каскадное удаление) |
| name | CharField(200) | название тура |
| country | CharField(50) | страна - необходима для таблицы продаж по странам |
| description | TextField | описание |
| date_start | DateField | период проведения: начало |
| date_end | DateField | период проведения: окончание |
| payment_terms | CharField(200) | условия оплаты |
| price | DecimalField(10,2) | цена |

Цена - `DecimalField`, а не вещественное поле: деньги требуют точного
десятичного представления, двоичный float даёт погрешности.

## Reservation - резервирование

| Поле | Тип | Комментарий |
|---|---|---|
| user | FK → User | кто забронировал |
| tour | FK → Tour | какой тур |
| guests | PositiveSmallIntegerField | количество мест (редактируется пользователем) |
| status | CharField, choices | `pending` (ожидает) / `confirmed` (подтверждено) |
| created_at | DateTimeField(auto_now_add) | дата создания |

Ограничение `UniqueConstraint(user, tour)` - один пользователь бронирует тур
один раз; дубли отсекаются самой базой данных.

## Review - отзыв

| Поле | Тип | Комментарий |
|---|---|---|
| author | FK → User | комментатор |
| tour | FK → Tour | тур |
| rating | PositiveSmallIntegerField | рейтинг, валидаторы 1–10 |
| text | TextField | текст |
| tour_date_start | DateField | даты тура, зафиксированные в момент отзыва |
| tour_date_end | DateField | (требование задания) |
| created_at | DateTimeField(auto_now_add) | дата отзыва |

Даты тура сохраняются в отзыве намеренно: отзыв документирует период, на
который ездил человек, независимо от последующих изменений расписания тура.
Ограничение `UniqueConstraint(author, tour)` - один отзыв на пользователя
на тур.

## Связи

```
User 1 ──── М Reservation М ──── 1 Tour М ──── 1 Agency
User 1 ──── М Review       М ──── 1 Tour
```
