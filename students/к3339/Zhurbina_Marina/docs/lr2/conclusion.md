# Выводы

В ходе лабораторной работы разработан сайт туристической фирмы на Django
с базой данных PostgreSQL. Реализованы все пункты варианта 4:

| Требование | Реализация |
|---|---|
| Хранение данных о турах | модели Agency, Tour (описание, период, условия оплаты, цена) |
| Регистрация пользователей | UserCreationForm, LoginView/LogoutView |
| Просмотр и резервирование туров | список с фильтрами, кнопка брони (POST) |
| Редактирование и удаление своих резервирований | страница «Мои брони», доступ ограничен владельцем |
| Отзывы (даты тура, текст, рейтинг 1–10, комментатор) | модель Review со снимком дат тура |
| Подтверждение резервирования в Django-admin | действие «Подтвердить выбранные брони» |
| Таблица проданных туров по странам | агрегатный запрос GROUP BY на странице /sales/ |
| Стилизация, пагинация, фильтрация, права is_staff | см. раздел «Реализация функционала» |

В работе закреплены: архитектура MTV, ORM и миграции, связи «один-ко-многим»
и «многие-ко-многим», представления на функциях и классах, формы и валидация,
аутентификация и сессии, защита доступа к данным, агрегатные запросы,
наследование шаблонов, работа с PostgreSQL и статическими файлами.

## Запуск проекта

```
python manage.py runserver
```

Учётные записи демонстрации: администратор - admin/adminadmin,
пользователи - ivan/user12345, maria/user12345.
