### Описание предметной области

Разрабатываемое веб-приложение предназначено для организации и отображения информации об автомобильных гонках.

Система позволяет хранить сведения о гонках, командах, автомобилях и гонщиках, регистрировать участников на соревнования, обрабатывать заявки и отображать результаты заездов.

В системе предусмотрены две основные категории пользователей:

- **Участник** — может зарегистрироваться, заполнить профиль гонщика, просматривать гонки, подавать заявки на участие и оставлять комментарии.
- **Администратор** — может управлять данными системы, просматривать заявки и подтверждать или отклонять участие гонщиков.

---

### Реализованный функционал

#### 1. Регистрация и аутентификация пользователей

В приложении реализована регистрация новых пользователей и система аутентификации на основе встроенных механизмов Django.

Пользователь может:
- создать учётную запись;
- войти в систему;
- выйти из системы;
- просмотреть и заполнить свой профиль гонщика.

#### 2. Просмотр списка гонок

Реализована страница со списком автомобильных гонок.

Для каждой гонки отображаются:
- название;
- описание;
- место проведения;
- дата начала;
- статус регистрации участников.

Предусмотрены дополнительные возможности:
- поиск гонок по названию и месту проведения;
- фильтрация по статусу регистрации;
- сортировка по дате или названию;
- постраничная навигация (пагинация).

#### 3. Регистрация на гонки

Авторизованные пользователи могут подавать заявки на участие в гонках.

При подаче заявки:
- проверяется, открыта ли регистрация;
- проверяется отсутствие ранее поданной заявки от этого пользователя;
- заявка сохраняется в базе данных;
- заявке присваивается статус ожидания подтверждения.

Пользователь может просматривать список собственных заявок и их текущие статусы.

#### 4. Управление заявками

Для администратора реализована отдельная страница управления заявками.

Администратор может:
- просматривать поступившие заявки;
- подтверждать участие гонщика;
- отклонять заявки.

После обработки заявки её статус изменяется в базе данных.

#### 5. Просмотр результатов гонок

Для каждой гонки предусмотрена отдельная страница с подробной информацией.

На странице отображаются результаты заездов:
- имя гонщика;
- команда;
- автомобиль;
- номер заезда;
- время прохождения;
- занятое место;
- количество набранных очков.

Результаты упорядочиваются по занятому месту и времени прохождения.

#### 6. Комментарии и оценки

Пользователи могут оставлять комментарии к проведённым гонкам.

При добавлении комментария указываются:
- тип комментария;
- текст сообщения;
- оценка от 1 до 10.

На странице гонки отображаются комментарии пользователей и средняя оценка гонки.

### Структура базы данных

В приложении используются следующие основные модели:

- **User** — пользователь системы. Расширяет стандартную модель пользователя Django.
- **Team** — гоночная команда.
- **Car** — автомобиль участника.
- **DriverProfile** — профиль гонщика, связанный с пользователем, командой и автомобилем.
- **Race** — информация об автомобильной гонке.
- **Registration** — заявка гонщика на участие в гонке.
- **RaceResult** — результат участия гонщика в конкретной гонке.
- **Comment** — комментарий и оценка гонки.

Связи между моделями реализованы с использованием внешних ключей (ForeignKey), связей один-к-одному (OneToOneField) и ограничений целостности данных.

Для взаимодействия с базой данных используется Django ORM.

### Запуск проекта

1. Перейти в корневую папку проекта.
2. Создать виртуальное окружение:

```bash
python -m venv .venv
```

3. Активировать виртуальное окружение.

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

4. Установить Django:

```bash
pip install django
```

5. Выполнить миграции базы данных:

```bash
python manage.py migrate
```

6. При необходимости создать администратора:

```bash
python manage.py createsuperuser
```

7. Запустить сервер разработки:

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

http://127.0.0.1:8000/

Административная панель Django:

http://127.0.0.1:8000/admin/
